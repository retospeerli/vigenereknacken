2. So funktioniert das Knacken

  1. Beim Vigenère-Verfahren bestimmt jeder Buchstabe des Schlüsselwortes eine eigene Verschiebung.
  2. Der Kasiski-Test sucht wiederholte Buchstabengruppen im Geheimtext.
  3. Die Abstände zwischen diesen Wiederholungen werden gemessen.
  4. Häufige Teiler dieser Abstände können auf die Länge des Schlüsselwortes hinweisen.
  5. Wenn die Schlüssellänge bekannt ist, wird der Text in Gruppen aufgeteilt.
  6. Jede Gruppe wird untersucht, um den passenden Schlüsselbuchstaben zu finden.
